## Overview

This repository is a **monorepository** managed with **TurboRepo** and **npm workspaces**. It contains two independent React applications (`project1` and `project2`) and shared packages (`packages`). All source code is written in TypeScript.

| Project | Purpose | DevPort |

|------------|-----------------------------------|------------|

| project1 | User Management (form + list) | 5173 |

| project2 | Test Showcase (Counter + Jest + Cypress) | 5174 |

## Folder and File Structure

```
group_task/
├── apps/ # Executable applications
├── packages/ # Code shared between apps
├── .gitignore # Files that Git should not version
├── package.json # Monorepo root configuration
├── package-lock.json # Exact dependency versions
├── turbo.json # Turborepo task pipeline
├── README.md # Quick start guide
└── DOCUMENTATION.md # This file
```

### Monorepo Root

| File / Folder | Purpose |

-------------------|----------------|

`package.json` | Defines the monorepo, workspaces (`apps/*`, `packages/*`), and global scripts (`dev`, `build`, `test`, `test:e2e`). |

`package-lock.json` | Locks installed versions for reproducible builds. |

`turbo.json` | Orchestrates tasks across projects (build, test) with caching and dependencies (`dependsOn`). |

`README.md` | Quick start guide: installation, commands, and ports. |

`DOCUMENTATION.md` | Extended documentation of architecture and dependencies. |

`.gitignore` | Excludes `node_modules`, builds, caches, and sensitive files from version control. |

`node_modules/` | Installed dependencies (not pushed to Git). |

`.turbo/` | Turborepo local cache (not pushed to Git). |

### `apps/project1/` — User Management

React application with registration form, validation, and a global user list.

| File / Folder | Purpose |

-------------------|----------------|

`package.json` | Dependencies and scripts for project 1. |

`index.html` | HTML entry point; mounts the app in `#root`. |

`vite.config.ts` | Vite configuration: React plugin, alias `@/`, and port 5173. |

`tsconfig.json` | TypeScript configuration for the app (extends `@repo/typescript-config`). |

`tsconfig.node.json` | TypeScript only for `vite.config.ts`. |

`src/main.tsx` | React startup: wrap the app with `ChakraProvider`. |

`src/App.tsx` | Main layout: title, form, and user list. |

`src/vite-env.d.ts` | Vite types for the browser environment. |

`src/schemas/userSchema.ts` | Zod schema: name ≥ 3 characters and valid email. |

`src/stores/userStore.ts` | MobX store with `makeAutoObservable`: user list and `addUser`. |

`src/components/UserRegistrationForm.tsx` | Form with React Hook Form + Chakra UI (inputs, errors, button). |

`src/components/UserList.tsx` | Reactive list with MobX `observer` displaying registered users. |

`dist/` | Production build generated by `npm run build` (no versioning). |

**Data flow in project1:**

```
User enters form

→ React Hook Form + Zod validate

→ userStore.addUser() (MobX)

→ UserList (observer) is re-rendered
```

### `apps/project2/` — Testing showcase

React application with a counter and unit and integration test suite (Jest/RTL) and E2E (Cypress).

| File / folder | Purpose |

|-------------------|----------------|

`package.json` | Dependencies, `test` and `test:e2e` scripts. |

`index.html` | Application HTML entry. |

`vite.config.ts` | Vite on port 5174. |

`tsconfig.json` | App TypeScript; excludes `*.test.tsx` files from the build. |

`tsconfig.test.json` | TypeScript configuration used only by Jest. |

`tsconfig.node.json` | TypeScript for `vite.config.ts`. |

`jest.config.cjs` | Jest configuration: jsdom, ts-jest, routes, and setup. |

`jest.setup.ts` | Imports matchers from `@testing-library/jest-dom`. |

`cypress.config.ts` | Base URL, specs folder, and Cypress support. |

`cypress/e2e/counter.cy.ts` | End-to-end testing: Visit the app and simulate clicks on the counter. |

`cypress/support/e2e.ts` | Cypress global support file (optional hooks). |

`src/main.tsx` | Mounts `App` in the DOM. |

`src/App.tsx` | Page with shared title and `Count` component
